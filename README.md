# Tab Customizer

탭 이름과 아이콘을 사이트마다 원하는 대로 바꾸고, 원치 않는 사이트는 자동으로 닫아 주는 Chrome 확장 프로그램입니다.

> PC용 Chrome 지원

## 주요 기능

- **탭 이름·아이콘 바꾸기** — 사이트마다 탭 이름과 아이콘(이모지 또는 직접 올린 그림)을 정합니다. 알림 숫자는 그대로 유지되고, 꾸민 탭을 북마크해도 원래 이름으로 저장됩니다.
- **탭 자동 정리** — 사이트를 열 때 탭 그룹으로 묶거나 탭을 고정합니다.
- **사이트 차단** — 등록한 사이트가 새 탭·팝업 창으로 열리면 닫고, 보던 탭이 넘어가면 이전 페이지로 되돌립니다.
- **옴니툴 연동** — 옴니툴의 차단 목록을 Chrome에 바로 반영합니다.
- **백업·복원** — 설정을 파일로 저장하고 불러옵니다.

## 설치 방법

1. 받은 압축 파일을 계속 둘 위치에 풉니다. (폴더를 지우거나 옮기면 동작하지 않습니다)
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위의 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 압축을 푼 `TabCustomizer` 폴더를 선택합니다.

업데이트할 때는 새 파일로 폴더를 덮어쓴 뒤 `chrome://extensions`에서 **새로고침(↻)** 을 누릅니다. 업데이트 전에 관리 페이지에서 **백업 파일 저장**을 해 두면 안전합니다.
