> PC용 Chrome 지원

Tab Customizer 첫 정식 버전입니다.

### 탭 꾸미기
- 사이트별 탭 이름·아이콘 변경 (이모지 9개 분류, 자동 선택)
- 주소로 탭 이름 자동 만들기
- 이름을 바꿔도 알림 숫자 유지
- 사이트별 탭 그룹 자동 묶기 / 탭 자동 고정
- 꾸미기 전체 ON/OFF, 사이트별 ON/OFF

### 사이트 차단
- 등록한 사이트가 새 탭·팝업 창으로 열리면 자동으로 닫기
- 보던 탭이 차단 사이트로 넘어가면 이전 페이지로 되돌리기
- 팝업·관리 페이지·최근 닫힌 탭 목록에서 등록
- 차단 전체 ON/OFF, 사이트별 ON/OFF

### 옴니툴 연동
- 옴니툴 차단 목록 실시간 반영
- Chrome을 켤 때 꺼져 있던 동안의 변경 내용 반영

### 관리·편의
- 관리 페이지 (밝은 화면·어두운 화면 지원)
- 설정 백업·복원 (합치기 / 전부 바꾸기)

### 설치
`TabCustomizer-1.0.0.zip`을 받아 압축을 푼 뒤, `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**로 `TabCustomizer` 폴더를 선택합니다.
