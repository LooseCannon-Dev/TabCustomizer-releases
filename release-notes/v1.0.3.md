> PC용 Chrome 지원

Tab Customizer 1.0.3 정식 버전입니다.

### 새 기능
- 그룹 접기 단축키
  - 보던 탭이 그룹 안이면 그 그룹을 접고 그룹 밖에서 마지막으로 보던 탭으로 넘어갑니다
  - 그룹 밖에서 누르면 창의 그룹을 모두 접고, 이미 모두 접혀 있으면 모두 펼칩니다
  - 직접 만든 그룹에도 적용됩니다
- Chrome 단축키: 기본 **Ctrl+Q**, Chrome 단축키 설정에서 바꿀 수 있으며 주소창·새 탭에서도 동작합니다
- 확장 단축키: 관리 페이지에서 원하는 키 조합을 직접 눌러 정합니다
  - Ctrl·Alt·Shift·Win 을 자유롭게 섞을 수 있습니다
  - Chrome 기본 단축키와 Alt+F4 는 정할 수 없습니다
  - 웹페이지를 보고 있을 때 동작합니다
- 백업 파일에 확장 단축키도 함께 저장·복원

### 설치
`TabCustomizer-1.0.3.zip`을 받아 압축을 푼 뒤, `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**로 `TabCustomizer` 폴더를 선택합니다.

이전 버전을 쓰고 있었다면 새 파일로 폴더를 덮어쓴 뒤 **새로고침(↻)** 을 누릅니다. 업데이트 후 Chrome 단축키가 정해져 있지 않으면 관리 페이지의 'Chrome 단축키 설정 열기'에서 정할 수 있습니다. 업데이트 전에 관리 페이지에서 **백업 파일 저장**을 해 두면 안전합니다.
