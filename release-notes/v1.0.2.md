> PC용 Chrome 지원

Tab Customizer 1.0.2 정식 버전입니다.

### 새 기능
- 보던 탭을 닫으면 그룹 접기
  - 확장이 묶은 탭 그룹에서 보던 탭을 닫으면, 같은 그룹의 다른 탭 대신 그룹 밖에서 마지막으로 보던 탭으로 바로 넘어가고 그룹은 접힙니다
  - 그룹에 남은 탭은 닫히지 않으며, 그룹 이름표를 누르면 다시 펼쳐집니다
  - 관리 페이지에서 전체를 켜고 끄고, 그룹마다 따로 끌 수 있습니다 (처음에는 꺼져 있음)
- 백업 파일에 그룹 접기 설정도 함께 저장·복원

### 설치
`TabCustomizer-1.0.2.zip`을 받아 압축을 푼 뒤, `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**로 `TabCustomizer` 폴더를 선택합니다.

이전 버전을 쓰고 있었다면 새 파일로 폴더를 덮어쓴 뒤 **새로고침(↻)** 을 누릅니다. 업데이트 전에 관리 페이지에서 **백업 파일 저장**을 해 두면 안전합니다.
